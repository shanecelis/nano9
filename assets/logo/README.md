# Logo files

These are the Nano-9 logo files. The source file is the `nano-9-logo.aseprite`.
The rest are exports of it with various layers turned off.

``` sh
├── README.md
├── nano-9-logo-bw.png
├── nano-9-logo-dc.png
├── nano-9-logo-tc.png
├── nano-9-logo-tw.png
└── nano-9-logo.aseprite
```

The files have been named such that one can identify them based on the a two
character suffix. Here's what the legend means.

## Legend
- b - black
- w - white
- t - transparent
- c - color
- d - dark
